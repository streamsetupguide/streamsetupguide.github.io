What TorBox is

TorBox is a debrid service: it downloads torrents and Usenet posts on its own servers, and you stream or download the result directly — fast, private, and without seeding anything yourself. Its most popular use is powering Stremio (and similar apps) so streaming feels like a normal on-demand app instead of a torrent client.

  • Torrents + Usenet + web hosters in one subscription
  • Instant caching — popular releases are usually already on their servers, so playback starts immediately
  • One-time plans exist (buy 3/6/12 months, no auto-renew) — this matters for the math below
  • Cloud features: 1 TB AirLock storage, S3-compatible access (T3), unlimited RSS feeds

Setup in 5 minutes (TorBox → Stremio)

  1. Create a TorBox account. Tip: signing up through a referral link adds free bonus days to your first plan — both sides get extra days (mine is further down, use any one you find, the bonus is the same).
  2. In TorBox: Settings → API Key → copy the key.
  3. Install Stremio (free, all platforms).
  4. Add an addon that talks to TorBox. The beginner-friendly path is EasyTorbox — paste your API key, it builds your install link automatically. Power users run AIOStreams (more control, more setup) or Comet/Torrentio with the TorBox provider.
  5. Search any title in Stremio → pick the TorBox source → it plays.
That's genuinely it. The "hard" part people overthink is the addon step — EasyTorbox exists precisely because of that. Five minutes, no server, no VPN needed for streaming (the streams come from TorBox's infrastructure).

The cheap-months math (why people stack plans)

Because TorBox sells one-time plans and time stacks, the community's favorite game is buying time cheaply and letting it accumulate:

  1. Buy during sales. Black Friday historically knocks 30%+ off annual plans — and the discount locks for the life of the subscription in some years, while one-time plans just get cheaper outright.
  2. Stack, don't replace. Buying another plan while you have time left adds to your expiry (existing time + new time). People cancel-and-rebuy only when a sale requires it — check terms each time.
  3. Referral days are free time. A handful of referrals per year can add weeks on top.
  4. Do the division at checkout. The play: (plan price ÷ days covered) × 30 = your effective monthly cost. Annual plans during a 30% sale plus referral days are how people quote numbers like "under $2/month" — that math is real, but only during sale windows.

FAQ from real community questions

Is Usenet included?

Yes, Usenet downloads are part of the subscription (high-speed backend). Note that TorBox's built-in Usenet search has had periods of being unavailable — external NZB indexers still work fine for finding content, TorBox handles the download.

What's AirLock / T3?

AirLock is your personal cloud slice (1 TB) where downloads land and stay. T3 is S3-compatible read access to it — you can mount your TorBox storage with rclone or any S3 tool and stream your own media library from it (read-only).

Is this legal?

TorBox is a legitimate cloud service — what you download through it is on you, same as any downloader. It's popular in the Stremio ecosystem because it's fast and dead simple.

Free plan?

Yes — limited, and useful for testing the setup before paying anything. Recent policy changes restrict some free-tier features (e.g., large cached torrents), so treat it as a trial, not a lifestyle.
