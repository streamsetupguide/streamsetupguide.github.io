EasyTorbox vs AIOStreams vs Comet — which TorBox addon should you actually use?

All three tried on a real TorBox Pro account, on real hardware, for months — not a feature-list regurgitation. Here's who each one is for and where each one hurts.

The 10-second answer

New to this? EasyTorbox. Want one addon that aggregaes everything with heavy filtering? AIOStreams (with a wizard config). Want the lightest, fastest scraper with zero setup? Comet (or Torrentio with the TorBox provider). Power users end up running AIOStreams with Comet as a fallback — that's the honest endgame.

EasyTorbox — the on-ramp

A community web tool: paste your TorBox API key, pick a couple of toggles, it builds your Stremio install link automatically. You never see a config file.

  • Setup: ~2 minutes. Genuinely non-technical.
  • Catalog: solid defaults (Netflix-style layouts, sensible quality caps). Not customizable beyond its toggles.
  • Caching: good — it prefers cached results so playback starts fast.
  • Hurts when: you want unusual filters (specific release groups, per-genre quality rules, addon stacking). You'll outgrow it — and that's fine; it's designed as the on-ramp.

Start here: easy-torbox.github.io/stremio. Their community referral pool is also the friendliest way to grab a TorBox signup bonus — and my referral link is on the main guide page if you'd rather help a specific human.

AIOStreams — the workstation

A self-hostable (or free-instances) meta-addon: it sits between Stremio and your actual scrapers, merges results, and applies deep filtering — then formats everything into pretty catalogs.

  • Setup: 20–45 minutes done right. Community wizard configs (e.g. Tamtaro) cut this down but you still need to understand what you enabled.
  • Catalog: the best there is — AppleTV-style formatter layouts, per-quality caps, debrid-locked results, precache/preload options so episodes are ready before you click.
  • Caching: excellent when you enable precache; the first scrape is slower, everything after is instant.
  • Hurts when: something breaks mid-config and you're staring at a JSON blob. It also runs as a service — the free public instances can be busy at peak hours. If you self-host it on a small VPS or even a Raspberry Pi, it's rock solid.

Real talk from mnths of use: the AppleTV formatter + precache + preload combo is what makes Stremio feel like a $15/mo streaming service instead of a torrent client. Worth every minute of setup.

Comet — the speedrun

A lightweight scraper addon with built-in debrid support. No meta layer, no fancy catalogs — it searches, sorts by the debrid's cache, shows you results.

  • Setup: 1 minute. Install, paste API key, done.
  • Catalog: a plain list, sorted well. Functional, not pretty.
  • Caching: its whole personality — cache-first ordering means the top result almost always plays instantly.
  • Hurts when: you want ANY filtering beyond quality caps, or pretty browse catalogs. It's a search tool, not a library experience.

The endgame setup (what we run)

  1. AIOStreams with a hardened community config (AppleTV formatter, 4K-allowed on big screen stuff, precache on).
  2. Comet installed as the fallback when AIOStreams' instance is busy.
  3. TorBox settings: 10 slots respected, RSS feeds for weekly shows so episodes land automatically (the main guide covers the Trakt→RSS trick).
